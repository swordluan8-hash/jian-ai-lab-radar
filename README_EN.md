# Jian AI Lab · GitHub Radar

A daily, verified radar for open-source projects discovered through GitHub Trending and X. We turn repository pages into practical Chinese introductions that explain the value, fastest start, real use case, and cost or setup threshold.

[Jian AI Lab](https://jianailab.com) · [Project Library](https://jianailab.com/library) · [Arena](https://jianailab.com/community) · [中文](README.md)

## Latest edition · 2026-08-29

The latest edition verifies ten new repositories and records a complete experiment with [Scientific Agent Skills](daily/2026-08-29.md). The report preserves the measured result, failed run, repair, artifacts, and practical limits.

## What makes this different

- Trending is treated as a temporary attention signal, not a quality certificate.
- Every entry is checked against the official repository and README.
- Changing numbers are timestamped.
- Authors and original discovery sources remain linked.
- Structured data is available in [`data/projects.json`](data/projects.json).
- A complete daily Chinese edition is published under [`daily/`](daily/).

## Daily process

1. Scan GitHub Trending for Today and This week.
2. Search X for the author and credible explainers.
3. Verify the repository, README claims, activity, language, and license.
4. Reject duplicates, dead repositories, and misleading claims.
5. Publish a practical Chinese introduction and link readers back to the original work.

Project submissions are welcome through the repository issue form. Inclusion follows verification and is never automatic.
