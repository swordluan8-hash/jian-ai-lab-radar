# 2026-08-27｜今日核验的 11 个 GitHub 项目

今天的第一条是 GitHub 全球今日 Trending 榜首 Archify，其余十条来自 X 传播线索并经官方仓库核验。Star 是核验时快照，不是永久数据。

## 1. Archify

把系统描述或代码仓库交给 Codex、Claude Code、Cursor 等 Agent，就能生成架构图、工作流图、时序图、数据流图和生命周期图，并导出自包含 HTML、PNG、SVG、WebM 与分享卡。

最短上手：`npx skills add tt-a1i/archify -g`。安装后可以直接说：“使用 Archify 分析这个仓库，画出 8—12 个核心组件、主调用路径、外部依赖和信任边界。”

它的区别是先用结构化数据和规则检查图中关系，再交付可交互结果。适合代码评审、系统讲解和技术文档。MIT 许可；Skill 免费，模型或 Agent 费用另计。

[GitHub](https://github.com/tt-a1i/archify) · [作者登顶记录](https://x.com/t20000622yy/status/2092793107129749634) · [中文项目页](https://jianailab.com/projects/archify)

## 2. Open Notebook

可本地或自托管的 NotebookLM 替代方案，能整理 PDF、视频、音频、网页和 Office 文档，完成搜索、资料对话、笔记和多角色播客生成。安装 Docker、启动官方 compose 文件，再在网页里配置 Ollama 或模型 API 即可开始。

[GitHub](https://github.com/lfnovo/open-notebook) · [X 来源](https://x.com/VaibhavSisinty/status/2089043855689805834) · [中文项目页](https://jianailab.com/projects/open-notebook)

## 3. No AI Slop

检测 20 多类常见 AI 写作模式。把规则交给支持 Skills 的 Agent，再让它标出假感悟、夸张转折和多余开场，并逐句给出不改变原意的改法。

[GitHub](https://github.com/petergyang/no-ai-slop) · [X 来源](https://x.com/VaibhavSisinty/status/2089043867534516555) · [中文项目页](https://jianailab.com/projects/no-ai-slop)

## 4. OpenSEO

自托管关键词研究、排名跟踪、SEO 审计和竞品分析工作台。部署后接入自己的站点与数据源，可以查排名下滑页面、补写关键词和竞争网站缺口。

[GitHub](https://github.com/every-app/open-seo) · [X 来源](https://x.com/VaibhavSisinty/status/2089043891005932013) · [中文项目页](https://jianailab.com/projects/open-seo)

## 5. OmniRoute

让 Claude Code、Codex、Cursor 等编程 Agent 共用一个多模型入口。接入已有模型账号后，主线路额度耗尽或服务失败时可以自动切到备用模型。

[GitHub](https://github.com/diegosouzapw/OmniRoute) · [X 来源](https://x.com/VaibhavSisinty/status/2089043914527482112) · [中文项目页](https://jianailab.com/projects/omniroute)

## 6. AI Job Search

把岗位评估、简历定制、求职信和面试准备组织成一套本地 Claude Code 工作流。复制仓库、填写真实履历，再按目标岗位运行流程；不能让模型虚构经历。

[GitHub](https://github.com/MadsLorentzen/ai-job-search) · [X 来源](https://x.com/VaibhavSisinty/status/2089043926355415409) · [中文项目页](https://jianailab.com/projects/ai-job-search)

## 7. Strix

让 AI Agent 探索 Web 应用、API 和代码中的安全问题，生成漏洞利用证据和修复建议。部署并配置模型后，只能填写自己拥有或明确获授权的测试目标。

[GitHub](https://github.com/usestrix/strix) · [X 来源](https://x.com/VaibhavSisinty/status/2089043938179174429) · [中文项目页](https://jianailab.com/projects/strix)

## 8. Open Generative AI

在统一界面组织 500 多个图片、视频与口型同步模型。部署网页应用并配置模型服务后，可以在同一项目里完成产品图、图片转视频和口型同步。开源的是工作台，模型与算力不一定免费。

[GitHub](https://github.com/Anil-matcha/Open-Generative-AI) · [X 来源](https://x.com/VaibhavSisinty/status/2089043950099444131) · [中文项目页](https://jianailab.com/projects/open-generative-ai)

## 9. Freecut

让 Codex 或 Claude Code 参与素材分级、剪辑、字幕、转场和动画叠加，并用本地 Whisper 等方案替代付费转写。需要准备 Python、FFmpeg 和本地转写环境。

[GitHub](https://github.com/Moh4696/freecut) · [X 来源](https://x.com/exploraX_/status/2072277788967481683) · [中文项目页](https://jianailab.com/projects/freecut)

## 10. Pentest AI

每个 AI 发现的漏洞都要经过机器复测，确认后才附可重放证据包进入报告。适合减少自动扫描误报，只能用于自有或获授权目标。

[GitHub](https://github.com/0xSteph/pentest-ai) · [X 来源](https://x.com/Manfridayy/status/2092887388100178236) · [中文项目页](https://jianailab.com/projects/pentest-ai)

## 11. Agent Orchestrator

在 Agent IDE 中规划任务、派生编程 Agent，并处理 CI 修复、合并冲突和代码审查。适合把一个可拆分的目标同时交给前端、后端和测试 Agent 推进。

[GitHub](https://github.com/Untrivial-ai/agent-orchestrator) · [X 来源](https://x.com/Maaztwts/status/2092883442082214011) · [中文项目页](https://jianailab.com/projects/agent-orchestrator)
