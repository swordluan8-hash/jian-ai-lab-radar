## 十项新收录（已作废的旧 Trending 草稿，仅保留审计痕迹）

### 1. GitNexus

[官方仓库](https://github.com/abhigyanpatwari/GitNexus) 把本地仓库、GitHub、GitLab、Azure 或 ZIP 变成浏览器内的代码知识图谱，并提供 Graph RAG Agent。它适合接手旧项目、追踪函数和调用链，或者让 Agent 在改代码前先理解影响范围。

GitHub Trending Today 排名第 5，核验时约 46,236 Stars，主语言 TypeScript，仓库未被标记为归档。当天发现来源是 [Product Hunt 的项目介绍](https://x.com/ProductHunt/status/2093054760228434331)。许可信息在 GitHub API 中未识别为标准 SPDX 值，使用前应回到仓库查看许可文件。

### 2. Cursor Plugins

[Cursor 官方插件仓库](https://github.com/cursor/plugins) 提供 Gmail、Google Drive、日历、GitHub、Playwright、持续学习、审查画布和编排等插件。价值在于把常用工具接进 Agent 的工作上下文，减少每次重新解释连接方式的成本。

它在 GitHub Trending Today 排名第 8，核验时约 6,030 Stars，主语言 TypeScript，许可为 MIT。Cursor 官方通过 [Agent Plugins 介绍](https://x.com/cursor_ai/status/2085464617694777762) 说明了这套插件方向。具体插件仍需分别配置服务账号和授权。

### 3. OpenLogi

[OpenLogi](https://github.com/AprilNEA/OpenLogi) 是 Logitech Options+ 的本地优先替代，使用 Rust 通过 HID++ 配置兼容设备的按键、DPI、SmartShift 和应用配置。它的直接卖点是不要账号、不要遥测，适合只想控制自己的鼠标和键盘的人。

核验时约 17,479 Stars，主语言 Rust，许可为 Apache-2.0，仓库仍在维护。项目介绍来自 [GitHubProjects 的 X 帖](https://x.com/GithubProjects/status/2061032448151183561)。Windows 支持仍需按具体设备确认。

### 4. OpenHuman

[OpenHuman](https://github.com/tinyhumansai/openhuman) 把个人长期记忆、多 Agent 编排、深度研究和应用工作流放进一个桌面平台。它适合想让 AI 逐渐了解个人资料、连接应用并持续执行任务的人，但项目仍标注 Early Beta。

核验时约 38,763 Stars，主语言 Rust，许可为 GPL-3.0，仓库仍在维护。官方项目账号 [tinyhumansai](https://x.com/tinyhumansai) 是本次来源。部分 OAuth、同步和模型能力依赖外部账号或项目服务。

### 5. FreeLLMAPI

[FreeLLMAPI](https://github.com/tashfeenahmed/freellmapi) 把用户自己申请的多家免费模型层放到一个 `/v1` 接口后面，支持智能路由、自动回退和加密密钥管理。它适合原型、学习和轻量自动化，避免一个免费额度耗尽就整条流程停掉。

它在 GitHub Trending Today 排名第 13，核验时约 21,769 Stars，主语言 TypeScript，许可为 MIT。开发者给出的项目说明包含 34 家提供商和 635 个端点，但免费额度、地区和长期可用性要以各提供商为准。相关传播来源是 [unwind_ai_ 的 X 帖](https://x.com/unwind_ai_/status/2092442471435534504)。

### 6. Music Assistant

[Music Assistant](https://github.com/music-assistant/server) 是连接流媒体、本地曲库和联网音箱的媒体管理器。服务器需要运行在 Raspberry Pi、NAS、NUC 等常开设备上，再通过 Home Assistant 或其他播放器完成多房间和自动化控制。

核验时约 3,008 Stars，主语言 Python，许可为 Apache-2.0。项目官方明确把服务器视为核心组件，并在 2026 年 8 月仍有维护。功能方向由 [Home Assistant 的公开介绍](https://x.com/home_assistant/status/2064784746064879793) 补充说明。

### 7. Awesome Agent Skills

[Awesome Agent Skills](https://github.com/VoltAgent/awesome-agent-skills) 是跨客户端的 Skills 精选索引，收录来自官方团队和社区维护者的一千多项能力，兼容 Claude Code、Codex、Gemini CLI、Cursor 等工具。它适合找入口，不应被理解为统一安全审计或质量背书。

核验时约 33,122 Stars，GitHub 未给出单一主语言，许可为 MIT，仓库仍在维护。它在 GitHub Trending This week 中保持较高位置，本次还参考了 [X 上的中文介绍](https://x.com/sitinme/status/2093250482118824400)。安装任何具体 Skill 前都要单独看源码、权限、网络调用和依赖。

### 8. agents-radar

[agents-radar](https://github.com/duanyytop/agents-radar) 每天抓取 GitHub、ArXiv、Hacker News、Hugging Face、Product Hunt、Dev.to 等十类来源，去重后生成中英双语日报、网页、RSS 和 MCP 数据。它适合持续跟踪 AI 项目与选题，不必每天手动翻多个站点。

核验时约 1,016 Stars，主语言 TypeScript，许可为 MIT，GitHub Actions 在 2026 年 8 月 29 日仍有自动运行证据。项目介绍参考 [BTCqzy1 的 X 帖](https://x.com/BTCqzy1/status/2093277270165307630)。自行运行时需要 GitHub Actions 配置和所选模型服务。

### 9. OpenBot

[OpenBot](https://github.com/CopilotKit/OpenBot) 给每个 AI 同事独立的 Chromium、登录态、文件和工作区，动作先经过策略判断，执行后写入 PostgreSQL 审计记录。它的实际价值是让 Agent 执行真实工作时保留可审批、可接管和可追溯的边界。

核验时约 3,343 Stars，主语言 TypeScript，许可为 MIT，项目仍标注 Alpha。官方部署路线需要 Docker、Bun 1.3+、CopilotKit Intelligence 项目和模型密钥。来源是 [CopilotKit 的公开发布帖](https://x.com/CopilotKit/status/2090126358227894711)。

### 10. Screenshot to Code

[Screenshot to Code](https://github.com/abi/screenshot-to-code) 可以接收截图、网页 URL 和录屏，生成 HTML、Tailwind、React 或 Vue 代码，并继续在界面里迭代。它适合快速做原型或把现有视觉参考交给 Agent 继续开发。

它在 GitHub Trending Today 排名第 7，核验时约 75,708 Stars，主语言 Python，许可为 MIT。项目并不意味着生成过程免费，实际使用仍需要配置视觉模型或对应服务。当天参考的中文介绍来自 [AISuperDomain 的 X 帖](https://x.com/AISuperDomain/status/2093159028041880051)。

## 旧草稿误标的实验（不计入今日实验）

[Scientific Agent Skills](https://github.com/K-Dense-AI/scientific-agent-skills) 在 GitHub Trending Today 排名第 2，官方仓库列出 163 个可安装 Skill，并覆盖生物、化学、医学、药物发现、数据分析和科研写作等方向。Archify 已经完成过 #1 实验，因此今天选择这个 #2 项目，不把重复实验当成新工作。

本次只安装 `statistical-analysis` 和 `scientific-visualization` 两项，没有把“能够复制 163 项”写成“163 项全部通过”。实验预先规定使用 GitHub Trending 前 20 项数据做双侧 Spearman 检验，并进行 10,000 次 bootstrap。第一轮因为报告导出依赖 `tabulate` 缺失而退出 1，随后改用标准字符串表格，不额外安装依赖，第二轮退出 0。

最终结果是 Spearman rho = 0.0451，双侧 p = 0.8502，95% bootstrap 区间为 -0.3983 到 0.4754。这个 20 个仓库、单日样本没有证明累计 Star 与当天新增之间存在稳定的单调关系，也不能代表整个 GitHub，更不能推出因果结论。

完整实验报告、原始 CSV、脚本、JSON、PNG、SVG、失败日志和视频制作包已经归档在 [剑的 AI 实验室实验页](https://jianailab.com/reports/scientific-agent-skills-trending-analysis)。本次没有调用付费 API，剩余 161 个 Skill 没有逐项运行。
